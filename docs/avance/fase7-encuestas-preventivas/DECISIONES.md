# Decisiones

- La identidad combina deportista, programa, fecha civil de inicio, instrumento y autor. Se reutilizan la fecha vigente de inicio y el programa que el sistema considera activo. Las encuestas anteriores mantienen su combinación original.
- La inicial puede guardarse y presentarse dentro de los siete días previos al inicio. La final se habilita tras las ocho semanas completas. Un borrador inicial vencido queda identificado como tal. Para abrir semana 0 se usa una fecha de inicio futura registrada en el mecanismo existente. Si se cambia antes de la intervención, la fecha nueva identifica otro contexto y el borrador previo queda en el historial.
- Cada encuesta conserva el catálogo y el periodo exactos en JSON. Cada guardado exitoso crea una revisión autoral. El envío cierra la encuesta. Las correcciones posteriores y las excepciones de fecha quedan bloqueadas hasta que exista un procedimiento aprobado.
- Las escrituras usan revisión esperada, ID de operación y transacción serializable. Una respuesta perdida puede reintentarse con el mismo ID. Si otra pestaña guarda primero, se consulta el estado vigente y se elige qué contenido conservar. Datos locales sin guardar permanecen en la pantalla ante un error recuperable.
- El consentimiento de demostración es específico para encuestas, con versión, texto y fechas. El retiro bloquea el acceso y conserva evidencia. La demostración exige adultos con fecha declarada y requiere activar `PREVENTIVE_SURVEYS_DEMO=1` en un entorno local. Producción ignora ese indicador. El retiro es definitivo para esta versión de demostración.
- Fisioterapia necesita la misma atención documentada que para bienestar y solo recibe respuestas presentadas. Los borradores se reflejan como estado. Para el entrenador, el ámbito es una ficha asignada con autorización activa. Las preguntas describen prácticas del equipo y los registros pertenecen a ese entrenador. El administrador queda fuera de las rutas de contenido.
