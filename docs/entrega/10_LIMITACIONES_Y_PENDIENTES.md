# Limitaciones y pendientes

| Tema | Situación y trabajo pendiente |
| --- | --- |
| Evaluaciones funcionales | Se consultan registros iniciales y finales existentes. El equipo académico debe aprobar captura, unidades, puntuaciones, protocolos e interpretación de las pruebas finalmente elegidas. El proyecto menciona SEBT/YBT-LQ, FMS, LESS y Agility T-test. |
| Eficacia preventiva | La adherencia mide sesiones declaradas. Los resultados sobre lesiones o eficacia requieren estudio con diseño, datos y autorizaciones. |
| Recuperación de cuentas | Gmail aceptó y el usuario recibió un mensaje de prueba. La recuperación integral se verificó con SMTP TLS local. Falta completar el recorrido con un enlace recibido vía Gmail. |
| Dependencias | En la rama de estabilización se verificaron las versiones corregidas de Effect y deepmerge-ts en la cadena de Prisma CLI. Revisar nuevamente la auditoría y el artefacto al desplegar. |
| Privacidad institucional | Definir responsables, bases y autorizaciones de tratamiento, manejo de menores, acceso, auditoría, conservación y gestión de exportaciones. El registro público de producción queda bloqueado mientras el aviso siga en borrador. La aceptación registrada y la seudonimización son capacidades técnicas. |
| Producción | Pendiente validación de HTTPS, dominio, proxy, gestión de secretos, alertas, capacidad y restauración. |
| Compatibilidad manual | Probar Microsoft Excel, dispositivos físicos y otros navegadores con libros y registros sintéticos. Las pruebas responsive de referencia se ejecutaron en Brave. |
| Programa inicial | Una instalación con migraciones necesita cargar el plan aprobado con sesiones. El borrador de demostración carece de sesiones. |
| Alcance profesional | El entrenador depende de una asignación. El esquema actual da alcance de equipo a fisioterapia, sin una relación individual para segmentar su acceso. |
