# Recuperación de contraseña por correo

## Pide un enlace y crea una contraseña nueva {#recuperar} [par]

LuchaSegura envía el mensaje desde una cuenta de Gmail. Puedes recibirlo en Gmail o en otro proveedor de correo compatible si esa es la dirección con la que te registraste.

1. En **Iniciar sesión**, pulsa **¿Olvidaste tu contraseña?**
2. Escribe el correo registrado y pulsa **Enviar instrucciones**.
3. Revisa la bandeja de entrada. Busca el mensaje de recuperación de **LuchaSegura** y pulsa **Restablecer contraseña**.
4. Escribe y repite la contraseña nueva. Usa al menos diez caracteres, con letras y números.
5. Pulsa **Guardar contraseña** y luego **Ir a iniciar sesión**. Entra con la contraseña nueva.

### Si no llega el correo o el enlace no funciona

- **Si no recibes el correo**, revisa spam y comprueba que escribiste la dirección registrada. Espera el intervalo que indique la pantalla antes de volver a solicitarlo. Si perdiste acceso a esa dirección, pide ayuda a administración.
- **Si el enlace no abre el formulario**, pulsa **Solicitar nuevo enlace**. El enlace dura 30 minutos y sirve una sola vez. Usa el enlace más reciente.
